# Dental Notes Documentation System

A simple personal dental notes system for creating patient-specific encounter notes.

## Features

- Add and select patients
- Choose an encounter type
- Build notes using dropdown prompts for each section
- Generate and save notes locally in your browser
- Copy note text to clipboard

## Usage

1. Open `index.html` in your browser.
2. Add a patient and select the patient name.
3. Choose the encounter type.
4. Select options for each section, then click "Generate Note".
5. Save or copy the generated note.
